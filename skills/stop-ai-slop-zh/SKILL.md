# 中文表达精修

让读者更快理解内容，同时保留理解所需的解释。重点删去无关铺垫、导览元话、重复评价与结尾拔高，不把篇幅短当作唯一目标，也不把讲解压成术语清单。

本版改编自 VincentOld 的 stop-slop-zh，面向科研与知识笔记补充了保真边界；来源和改编说明见 [SOURCE.md](SOURCE.md)。它是一套编辑提示，不是 AI 文本检测器，不能证明文本由谁写成。

## 先保护内容

- 保留原意、专业术语、数值、单位、公式、代码、变量含义、成立条件与未解决问题。不能为了顺口，把“可能、至少、在……条件下、尚未验证”等范围或证据强度删掉。
- 区分论文事实、教学补充与待核实疑点；区分作者意图与公式实际保证，区分文本检查、代码复现、仿真与实际实验。遇到不能确认的内容，保留原限定，不用更肯定的措辞补齐。
- 不补造数据、案例、个人经历、来源或验证结果。需要具体材料却原文没有时，收窄表述、保留必要概括，或在用户要求审校时指出缺口。
- 润色已有笔记时保留标题与锚点、导航、图片与图注、引用、链接及别名、真实元数据。只改用户指定范围；不因润色自行重组全库、替换图表、安装技能或发布内容。

## 八条编辑思路

| 思路 | 实际判断 |
| --- | --- |
| 1. 删空话 | 删除不增加信息的开场、强调和重复复述。判断删后是否仍有完整意思，不按禁词表机械替换。 |
| 2. 拆机械排比 | 几项意思重复时合并；各项分别表达条件、步骤或结论时全部保留，可调整组织方式。三项本身不是问题。 |
| 3. 让动作清楚 | 能直接说“优化”时不必说“进行优化”；保留定义、模型与领域术语中有用的名词化。 |
| 4. 收住结尾 | 删除口号、重复总结和无依据的拔高；保留实际结论、限制、待办与对后文必要的衔接。 |
| 5. 主语准确 | 说清谁或什么产生作用。算法、设备、约束和模型都可以作准确主语，不强行换成人，也不编造执行者。 |
| 6. 让转折有用 | 删除空转的“接下来我们将”等元评论；保留表达因果、反例、条件和推导顺序的连接词。 |
| 7. 用已有细节说清楚 | 优先用原文已有的动作、对象和范围替代泛泛评价；不能用新编数字、场景或经历制造具体感。 |
| 8. 结构服务理解 | 按内容组织段落，不强套总分总；保留有用的层级、表格、设问和讲解顺序，不为了“去模板”打乱方法与证明。 |

自然的第一人称、口语、设问或感叹可以保留，但不强加熟人称呼、俏皮话或“真人经历”。句长、排比数量、连接词和词频都没有配额。

## 工作方式

先确定读者、用途和修改范围。只处理表达的任务，先识别不能改的技术与结构内容，再改冗余和拗口句。起草新内容时，在已有材料支持的范围内写清楚，不把缺失事实写成既成事实。

改完对照原文检查：条件是否少了，范围是否变窄或变宽，意图是否变成保证，疑点是否变成结论，必要解释是否被删，引用和导航是否仍指向原处。比较可在内存中完成。用户明确不要备份时，不创建备份、原稿副本或包含原稿全文的差异文件。

按任务需要读取参考：

- 判断某类措辞是否空泛：读 [措辞检查](references/phrases.md)。
- 处理排比、段落或技术论证：读 [结构检查](references/structures.md)。
- 不确定怎样改才能保留条件和口吻：读 [保真改写示例](references/examples.md)。

默认交付改写内容；用户要求说明时，列出影响理解的主要改动。若直接编辑文件，简述实际改动与检查范围。不为每篇笔记附上评分、编辑过程或自我评价，也不把文字对照检查说成事实核查或实验验证。

## 与 Obsidian 笔记配合

与笔记生成技能共同使用时，由主技能负责目录、查重、图片、引用格式与生成元数据；本技能负责表达，不能用文风要求覆盖内容和证据规则。独立处理 Obsidian 文本时也注意：

- 正文里的普通编号文献引用写成 `\[1\]`；已有 Markdown 链接、脚注语法、公式和代码按各自语法保留。
- 不用 `**` 包住 Markdown 链接或双链，也不把它放进链接文字或别名中。需要强调时，强调链接外的普通文字。
- 加粗结束后仍接正文时留一个空格，例如 `**结论。** 后文`。
- 独立的行间公式之间保留确有解释作用的正文；同一连续推导可放在同一数学块中。不要堆放相邻的 `$$` 块，也不为分隔而编一句空话；不改公式与代码语义。
- 保留已知的生成时间、模型和更新记录；无法确认的历史信息不补造。独立且仅润色表达时，元数据保持原样；随主技能落盘时，由主技能按任务维护真实更新时间与模型。用户本次明确要求冻结元数据时遵从，润色阶段不猜补任何字段。

## 五维复核（按需）

可用“直、实、变、散、真”讨论文本：是否直接到要点，是否有材料支持，句式是否随内容自然变化，组织是否清晰而不机械，口吻是否自然且忠于来源。用户要求量化时，可各给 1–10 分并说明具体依据。

这些分数是主观编辑意见，没有经过校准，也没有统一通过线。不能用总分替代内容保真，不能为了提分强行改写已经准确好读的句子。
