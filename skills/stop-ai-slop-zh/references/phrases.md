# 措辞检查：看它是否有用

这些词组是检查入口，不是黑名单。判断它在当前句子中是否表达事实、关系、范围、必要语气或个人感受；有作用就留。不能依据某个词或出现次数判断文本作者。

## 常见检查点

| 类别 | 常见表现 | 编辑判断 |
| --- | --- | --- |
| 空泛开场 | “在当今时代”“随着……不断发展” | 若只是拖延主题，可删。若交代真实背景和研究动因，保留必要事实与来源。 |
| 机械连接 | “首先、其次、最后”“综上所述” | 顺序、因果和结论确实依赖它们时保留；段落关系已清楚时可减。不要抹去条件与转折。 |
| 强调外壳 | “值得注意的是”“不可忽视的是”“显而易见” | 去掉后信息不变时删。若提醒读者某个容易误解的适用条件，保留条件本身。 |
| 抽象套语 | “赋能”“多维度”“形成闭环”“具有重要意义” | 优先写已有材料支持的对象、动作和结果。领域内确有定义的术语照用；缺材料时不要编具体成果。 |
| 程度与范围 | “非常”“显著”“一定”“可能”“至少” | 程度词需要证据；范围词往往决定命题含义。不能把“至少三项”压成“三项”，也不能把统计显著性改成口语程度。 |
| 导览元话 | “接下来我们将深入探讨”“本节旨在帮助读者理解” | 可直接进入内容；如果它承担必要导航，缩为明确入口。用户手册的操作引导不因像导览就删除。 |
| 拔高收尾 | “让我们共同迈向……”“这为未来打开无限可能” | 删除无材料支撑的升华。保留论文明确提出的应用前景，但维持原有条件和推测语气。 |
| 重复排比 | 多个近义评价连续出现 | 合并同义项。并列的独立条件、指标、限制或任务分别保留。 |
| 假亲切 | “宝子们”“你一定也遇到过” | 不替作者假定共同经历。原文已有、适合读者的自然称呼可以留，不给科研笔记强添口语标签。 |
| 评价先行 | “优秀”“高效”“突破性”“极具价值” | 有指标或原文评价就明确归属；没有证据时收窄评价，不把作者声称写成已经验证。 |
| 成语堆叠 | 连续四字词替代具体说明 | 信息空泛时改成清楚的动作。固定术语、自然表达和有意义的比喻无需为字数或词形而删除。 |
| 库存比喻 | “双刃剑”“冰山一角”“开启新篇章” | 比喻能准确解释机制时可留，并保留适用边界；只是装饰时删。不要为换比喻补造场景。 |

## 不要误删的表达

- “若、仅当、至少、至多、可能、通常、尚未”等词经常是命题或证据的组成部分。
- “约束、执行、优化、协同、鲁棒、韧性”等词在专业语境中可能有明确含义，不能因常见于宣传文就禁用。
- 算法可以搜索，约束可以排除不可行解，设备可以采集数据。主语是否准确，取决于实际机制，不取决于它是不是人。
- “为什么会这样？”若后文解释原因，可以保留；“这难道不令人振奋吗？”若只要求读者认同评价，可删除。
- 原文作者的“我当时不明白这一点”可以是有效的学习记录；润色者不能自己添加这类经历来制造人味。

## 替换时的边界

能从已有材料中找出细节，就用细节。没有细节，就保持有边界的概括。只删掉一个空洞形容词通常比补入一个无来源的数字更合适。

例如，原文只说“该方法可能降低通信开销”，可去掉前面的“值得强调的是”，但不能改成“该方法将通信开销降低一半”。如果用户要求的是表达润色，也不要悄悄查询别的论文，把新事实塞进原句。
