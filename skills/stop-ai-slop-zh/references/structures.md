# 结构检查：保住论证，再减冗余

先识别段落在做什么：定义、解释、推导、比较、列条件、记录疑点，还是提供操作入口。结构是否合适，要看用途。索引、使用手册、实验步骤、证明和概念笔记不必写成同一种文章。

## 常见结构及判断

| 结构 | 什么时候改 | 什么时候保留 |
| --- | --- | --- |
| 三项排比 | 三句只是换词赞同同一判断时，合并重复意思。 | 三个成立条件、设备限制或证据边界各有独立作用时全部保留。 |
| 二元对立 | “不是甲，而是乙”凭空制造对立时，改成直接陈述。 | 真正区分两种模型、机制或误解时，保留对比及边界。 |
| 名词化 | “对参数进行调整”可在合适语境中写成“调整参数”。 | 定义、目标函数、技术名称和正式责任表述中必要的名词短语。 |
| 长定语串 | 修饰关系难辨时，拆成定义和作用两句。 | 保留每个限定；不能拆句时丢掉对象、时间、条件或归属。 |
| 抽象主语 | “研究实现了提升”等句子没说清机制时，回到已有动作。 | 模型、算法、约束、设备和变量作为准确主语，无需改成人。 |
| 碎句强调 | 连续短句只制造戏剧感时，合回完整表达。 | 简短警告、真实个人感受、操作提示和有用的节奏变化。 |
| 设问或反问 | 只重复评价、没有后续解释时，直接说清内容或删除。 | 问题能引出机制、计算步骤、误区或尚待验证之处。 |
| 金句收尾 | 抽象升华、重复前文时，结束在实质内容处。 | 实际结论、限制、未解决问题、下一步操作。 |
| 总分总 | 开头预告、正文展开、结尾原样复述造成重复时，减掉一层。 | 摘要、正式报告、较长教程中有助定位与回顾的必要结构。 |
| 评价饱和 | 连续断言“高效、可靠、创新”却无支持时，收窄表述。 | 有出处的作者评价、明确指标与有边界的比较。 |
| 假亲切对话 | 假定读者经历、强加称呼和互动时，恢复准确叙述。 | 用户原有的自然口吻、学习时真实记录的困惑。 |
| 远距离叙述 | 抽象话反复绕开实际对象时，使用已有对象和动作。 | 不知作者或责任人时保持准确概括，不编造叙述者、团队或经历。 |
| 句长趋同 | 每句塞入同样多层信息、读着费力时，按信息关系拆合。 | 公式解释和连续步骤需要一定平行性；无需追求特定长短比例。 |
| 列表机械 | 把一段连贯推理拆成无层次的清单时，改回有联系的正文。 | 条件、步骤、符号和比较天然并列时，列表或表格更清楚。 |
| 段落等长 | 为凑版式重复填充时，删掉填充。 | 段长相近本身不说明有问题，不为打散外观删信息。 |

## 科研笔记中容易改坏的地方

**意图不等于保证。** “作者希望用该约束限制通信距离”不能仅为简洁改成“该约束保证通信距离合规”；应先知道公式是否确实保证。只做表达修改时保留原说法与疑点。

**分类不等于实现。** “这里区分供电与协调控制”不能擅改为“分别建模并验证了供电与协调控制”。后者增加了实现与验证信息。

**三条边界不是排比废话。** 未复现作者代码、教学修正不代表作者实现、仿真不证明真实设备能力，分别限制不同结论。可以组织得更好，但不能保留其中一条来“打破三件套”。

**相似名词不必有冲突。** 原文称某地“另有一个名称”，不能改成“却称……”，除非材料足以支持矛盾关系。

## 编辑与复核

需要调段时，先在脑中保留“命题—条件—证据—限制”的对应关系，再删掉不承担作用的句子。已有标题和锚点默认不改，避免影响链接；代码、公式、表格、图片、图注和导航不能当作冗余段落顺手重排。

改完可问：读者还知道这条结论在什么条件下成立吗？还分得清原论文说了什么、笔记补充了什么、哪些尚未确认吗？如果这些内容变模糊，即使文字更短，也应该恢复必要说明。
