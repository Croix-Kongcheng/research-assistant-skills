# 续写与审校模式

两种模式都先完整读取本技能的 [工作区配置](workspace-config.md) 和 [完整工作流](workflow.md)。只需本技能内的文件，不依赖私人母提示词或另一个技能；本次用户指令优先。

两种模式都沿用完整工作流的表达精简阶段：内容与事实核对后，默认使用可用的 `stop-ai-slop-zh`，保留必要解释、条件与证据强度；缺少技能时按自带规则完成，用户明确不润色时跳过。只处理本次涉及的笔记，不额外生成原稿备份或把编辑评分写进正文。

## 中断续写

需要能定位本次论文材料目录与已有论文笔记目录；用户已在当前上下文提供时不重复索取。按配置和实际文件解析知识 / 附件 / 索引位置。若换电脑后路径已变，用本次真实位置替换失效入口，并修复受影响链接。

1. 读取已有总览、专题、个人批注和可用进度，对照源文核实已完成到哪一节、哪一自然段、哪个编号 / 未编号公式与图表。不能只信上一轮“完成”的声明，也不能从头覆盖。
2. 默认沿用同篇现有位置；仅本次明确迁移时改变目录，默认保留旧名与编号。用户明确给出本篇完整目录时不再套子目录，改号仅在本次明确要求时执行。迁移、增补或拆篇联动修复知识引用、图片路径、索引和导航。
3. 从真实未完成处继续，补齐全部实质段落、数学关系、图表、算法、知识积累与链接，保留有效内容、个人表达和未证实的疑问。已核实的新结论说明依据，不把旧疑点无声删除。
4. 论文系列保留上一篇 / 下一篇 / 返回总览，与阅读地图相符。续写前重新检索已有知识（含上批落盘文件）的别名、缩写、中英文名及正文，读候选确认同概念：已有就引用，缺口补原篇，不重新建同义笔记；独立知识按主题互链，不编入论文顺序链。保持本次语言、文风和读者背景，不用“精简”省略要求覆盖的内容。
   同时补齐有助理解的图片：优先复用已有附件 / 原图，不足时按完整工作流主动联网核对来源、许可并下载，或自绘后就近插入解释；不把上一轮文字齐全当作配图已完成，不为补图复制已有知识点。
5. 新笔记文末记录真实生成时间 / 时区 / 模型；旧笔记保留历史生成信息，记录实际更新时间 / 模型，未知历史信息不倒填。继续持续落盘，确实中断才更新下一处断点。
6. 按完整工作流做对应检查后交付剩余工作，简述实际新增与核验范围，不重复只交计划。材料或能力仍缺失时具体标记未核验位置与影响。

## 审校与直接修订

需要本次论文材料和已有笔记位置。按实际工作区与配置解析关联知识、附件和索引；先全库核对同一论文，默认原处审校，明确迁移才改变位置，不另生成一套重复笔记。

1. 对照源 PDF 的实际页图核对章节 / 自然段、全部编号与未编号公式、行内关系、符号定义、图表、算法、条件、结果与实质附录。区分 OCR 转写错、作者原式疑点、笔记自身错误，以及本次材料无法确认的部分。
2. 原文没给出的推导、实验或验证不能补成作者的确定结论；自己补充的解释、假设、反例和候选修正要标明身份与依据。作者疑点保留原式、位置和证据，不悄悄替换成看似正确的表达。
3. 用名称变体、索引和正文重查关联知识，打开候选确认是否同一概念；已有同概念笔记优先引用或小幅补缺，不另建重复篇。发现历史重复时保留原文件和个人批注，不擅自删除 / 合并；明确同词异义的区别。检查定义是否混合领域、论文特例是否误写为通则，符号 / 单位 / 成立条件是否缺漏，是否仍存在与本次偏好冲突的模板或空泛表达。
   检查论文和知识笔记是否缺少本可帮助理解的结构、机制、几何、状态或公式示意；按完整工作流实际复用、联网获取或绘制并嵌入，核对内容、来源和许可，不只列“可补图”建议，也不为了数量添加装饰图。
4. 直接修正有证据的错误、补齐真实缺口，保留个人批注与尚未证实的疑问。改口吻不能删必要公式、图片、条件和细节；修订范围与证据相称，不进行无关重构。
5. 联动更新正文双向引用、知识索引、图片嵌入、专题篇尾导航和总览地图，按真实文件验证路径、LaTeX 和格式。独立概念按主题互链，不能串成论文课程。
6. 保留可核实的历史生成时间与模型；缺失历史信息如实写未知，记录本次实际更新时间、时区和模型，不凭文件时间猜历史。新补笔记仍按完整工作流写文末生成信息。
7. 最后简短报告直接修了什么、核查覆盖到哪里、实际执行了哪些检查、还有哪些具体位置缺证据。缺少 PDF 或页图能力时明确核验限制，不能用静态文件检查代替全文 / 渲染 / 实验验证。
