# MinerU 论文精读与知识积累

把一篇论文读到目标读者能理解每个实质性段落、全部公式和关键图表，并把可复用知识补进其知识库。论文笔记记录本文的模型、条件、结果与疑点；独立知识笔记解释概念本身，跨论文复用。完成实际文件，不能停在摘要、目录、计划或几篇样例。

## 先加载本技能的完整规则

三种模式都先完整读取：

1. [工作区配置](references/workspace-config.md)：解析知识库根目录、论文 / 知识 / 附件 / 索引位置，以及语言、文风、读者背景、时区和链接格式。用户明确要求优先，其次是可选 `research-skills.yaml`，再匹配实际工作区；不依赖特定盘符、用户名或个人笔记库。
2. [完整精读工作流](references/workflow.md)：全部阅读、数学解释、知识积累、图片、导航、进度、证据边界和文末信息要求。本入口不能代替该文件。

目标工作区已有写作规范或相近笔记时可按需参考。`chc-vault-notes`、PDF 或绘图专项技能均为可选协作，不是安装前提；不可用时仍执行本技能自带要求。普通笔记的精炼默认值不能用于省略本次要求覆盖的段落、公式或图表。

## 模式与输入

| 用户意图 | 执行方式 | 额外读取 |
|---|---|---|
| 精读论文并生成整套笔记 | 从材料检查做到落盘和完成检查；同篇已有笔记时在原处修订 | 无 |
| 继续上次、补齐中断任务 | 对照原文、实际文件和进度定位断点，保留批注与有效内容 | [中断续写](references/modes.md#中断续写) |
| 审校已有整套笔记、补漏或纠错 | 核对原文并直接修订确定错误和缺口，联动知识笔记及导航 | [审校与直接修订](references/modes.md#审校与直接修订) |

未明确模式时按用户意图判断，不强制先选模式。单独审校按需使用，不要求每篇完成后都另跑一轮。

需要已有的 MinerU 解析目录；源 PDF 在别处时也接受其实际路径。用户可指定知识库根、课题、精读根目录或本篇完整目录。续写 / 审校还需能明确定位已有论文目录。先检查实际 Markdown、JSON、图片及 PDF，不假定文件名固定。本技能不安装或启动 MinerU 服务。

完整执行需要文件读写、图片查看与 PDF 页面查看 / 渲染能力。缺少 PDF 或某项能力时继续可确认的内容，明确受影响的核验范围；不能声称已经完成做不到的检查。目标工作区不明确时只询问真正缺少的位置，同时继续材料身份和结构检查。

## 位置与交付约束

- **显式指定位置优先。** 本篇完整目录直接写入，精读根目录才在下面新建论文文件夹；只指定课题时，匹配配置 `topics` 或实际课题树。
- **先查同篇，保留既有位置。** 在目标知识库内按正式题名、DOI 或源 PDF 身份查重。续写、审校和再次精读沿用已有目录；明确要求迁移才移动，并修复引用。迁移默认保留原名和序号，明确要求重编号时例外。
- **按主要研究问题归类。** 未指定位置时检查真实课题结构、配置与论文主要贡献，不凭应用场景或“任务分配”“回归”“MILP”等通用方法词强行归类。没有匹配主题且归属明确时可在解析出的论文集合位置新增合适课题；多个归属同样合理而影响保存时再澄清。
- **编号只在选定精读根目录内递增。** 不硬编码首号、目录名或篇数，不为补缺号重排旧论文。
- **知识按概念独立积累。** 查重后复用、补充或新建，按实际领域分类，在正文就近双向互链并更新知识索引；不串成某篇论文的上下篇。
- **论文系列保留导航。** 按真实阅读地图连接上一篇、下一篇和返回总览；知识点去系列化不影响论文系列导航。图片实际保存到解析出的附件目录，就近嵌入并注明来源。
- **持续落盘并保留证据。** 全文覆盖、PDF 页图核验、图表来源、实际断点、个人批注和待核实事项都按完整工作流处理，不静默修正作者原式。
- **每篇文末有真实时间与模型。** 使用用户配置或实际本地时区，无法确认时用 UTC 并说明；模型只写当前环境明确提供的标识。旧笔记保留历史生成信息，追加本次更新时间 / 模型，缺失信息如实未知。

最终简短给出论文笔记入口、知识索引、新建 / 补充 / 复用的知识点、实际检查和仍缺证据的具体疑点。静态文件检查不等于笔记软件渲染，精读不等于代码复现、求解或实机验证。
