## 2. 复现前必须处理的疑点

这里每个疑点背后的检查方法，集中解释在 [数值尺度、容差与模型验证](../knowledge/%E6%95%B0%E5%80%BC%E5%B0%BA%E5%BA%A6%E3%80%81%E5%AE%B9%E5%B7%AE%E4%B8%8E%E6%A8%A1%E5%9E%8B%E9%AA%8C%E8%AF%81.md)；原文公式与通用教学模型的区别仍须保留。

“原文有疑点”不等于已经证明作者代码有同样错误。本次没有取得作者实现，因此下面判断仅针对印出的公式、文字与图表。

| 位置 | 已核对的现象 | 为什么影响理解/复现 |
|---|---|---|
| 式（4） | UAV 充电项为正号，电力节点与充电节点索引关系不清 | 可能把耗电当供电；需要明确符号方向和节点映射 |
| 式（11）（12） | 电压平方降落式没有常见的系数 $2$ | 不能静默套用常见 DistFlow 并假装与原式相同 |
| 式（15）—（19） | 支路求和域、等式/不等式叙述、岛数与正虚拟需求条件未完全一致 | 仅凭印刷式不能完整证明所有被供电部分为正确的辐射状森林 |
| 式（21） | 排除集合未清楚定义，且只有上界不等式 | 不能认为它固定了所有原始闭合状态 |
| 式（25）（39） | 时间窗口两端都计入，右侧长度少一；末时段仍列约束 | 可能多限制一时段，甚至在有多个候选点时强迫终端不连接 |
| 式（27）—（29） | MESS 的部分参数下标写成 UAV 索引 $z$ | 必须先确认设备索引，而不是把两类设备的参数混用 |
| 式（34） | 只给聚合有功上界；式（8）允许负供给 | 通信不可用不自动推出每台资源都零出力，也没直接限制所有开关 |
| 式（35） | 路径展开的因子与端点异常，出现未明确定义的 $v$ | 按字面抄写不保证表达节点到中央控制器的可达性 |
| 式（40） | 左侧 $n$、右侧 $i$，多机同点时可能得到负缺供 | 需要通信节点映射和覆盖逻辑，不能默认它已是通用覆盖模型 |
| 式（41）—（47） | UAV 能量消耗没有完整绑定飞行、悬停、服务状态，式（45）用 $\mathcal N_C$ | 仅有 SOC 更新不等于无人机续航模型完整，充电点与服务点也需区分 |
| 式（63）（64） | 最右端印为额定上限，而非设备实际功率 | 与 MESS 对应式不同，不能保证辅助功率等于二元状态乘实际功率 |
| 式（66）—（74） | 缺供与净流入语义冲突、失效边门控未写清、可用性相加不等于逻辑或 | 通信约束需重新核对，不能把所有表达默认视为严格等价变换 |
| 式（75） | $\rho$ 只说小正数，未给统一量纲和严格优先条件 | 加权目标不自动等价于“先最大恢复负荷，再最小通信缺供” |
| 表 II、V-A | 5 条/6 条通信故障、设备编号不一致；全网通信恢复与所有链路修好需区分 | 无法直接从叙述重建唯一恢复轨迹 |
| 图 4、6、12、13 | 初始 SOC 约 $0.8$，文字称满电 | 需确认初始 SOC 和可用上限，不能自行确定参数 |
| 表 VII 的 123 节点能量 | 超过同文负荷规模与 $24\,\mathrm h$ 对应的满供上界 | 单位、数值或统计口径至少有一项需要核实 |
| V-D 与表 IX | 维修边端点、时刻不一致，恢复节点有重复 | 会改变通信连通与供电可行性 |
| 图 13(a) | 图题是 MESS 功率，实际图例为 Wind/PV | 无法从该图核实 123 节点储能功率调度 |
| 表 VIII | 目标口径不同、缺少权重与求解证据 | 不能直接把数值差当最优性间隙、算法优越性或线性化误差证明 |

**一个能直接代入的核对例子。** 表 IV 给出 MESS-1 在节点 $29$ 连续占用第 $6,7$ 时段，站间旅行时间为 $1\,\mathrm h$。在式（25）中取未占用的候选节点 $i=15$、目的节点 $j=29$、$t=6$，左侧为 $\alpha^{\mathcal M}_{1,29,6}+\alpha^{\mathcal M}_{1,29,7}=2$，右侧为 $(1-\alpha^{\mathcal M}_{1,15,6})\min(1,24-6)=1$，得到不成立的 $2\le1$。表 V 的 UAV-1 在同样时段驻留 $29$ 也有对应问题。这证明公布的位置表与按字面读取的窗口约束不一致，但不能据此断言作者实际程序也照这个错误运行。

要做实现，最先需要补的是完整网络输入、维修状态生成规则、设备初始与终端条件、负荷权重、通信节点映射、无线服务与耗能规则，以及各类辅助变量的正确线性化。这里是根据模型依赖提出的复现准备，不是声称这些资料已经从作者处取得。

## 4. 怎样把这篇读成自己的研究材料

可以借鉴的首先是问题组织方式：从灾后电力与通信同时失效出发，区分临时通信支援与永久线路维修，再让通信恢复改变电力资源的可调度范围。这个因果链比直接照抄一串存在疑点的约束更有价值。

如果后续课题关注无人机航路规划，需要在本文离散站点模型外补充实际飞行可达性、任务切换时刻与飞行/悬停耗能；如果关注电网恢复，应先补齐网络拓扑、虚拟流、功率方向与通信逻辑，确认模型真的表达了设想的恢复机制。以上是基于精读提出的研究判断，不是论文已经实现的功能。
