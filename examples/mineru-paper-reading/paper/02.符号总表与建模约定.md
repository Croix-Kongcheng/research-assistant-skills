# 02. 符号总表与建模约定

本文符号多，主要因为它同时描述**电力网、通信网、移动储能、无人机，以及离散时间**。这里以 PDF 第 1—2 页的 Nomenclature 为基础，补齐第 III、IV 节才出现的符号。符号意义以正文使用为准；原文有混用的地方明确列出，不假装原符号表已经完整一致。

## 先学会拆一个符号

如果还不熟悉集合、索引、已知参数与决策变量，先看 [优化模型的基本语言](../knowledge/%E4%BC%98%E5%8C%96%E6%A8%A1%E5%9E%8B%E4%B8%AD%E7%9A%84%E5%8F%98%E9%87%8F%E3%80%81%E5%8F%82%E6%95%B0%E4%B8%8E%E5%8F%AF%E8%A1%8C%E5%9F%9F.md)，再回到本篇查这篇论文的具体符号。

例如 $\alpha^{\mathcal M}_{m,i,t}$：上标 $\mathcal M$ 表示 MESS 这一类设备，下标 $m$ 表示第几台，$i$ 表示哪个接入节点，$t$ 表示哪个时段。整体是一个二元变量，等于 $1$ 表示该台储能在该时段连接在该节点，等于 $0$ 表示没有连接。

$P^{\mathcal M}_{\mathrm{ch},m,t}$ 则是第 $m$ 台储能在时段 $t$ 的充电功率。$\mathrm{ch}$ 是充电标签，$\mathrm{dch}$ 是放电标签，不是额外的数学变量。$\overline P^{\mathcal M}_{\mathrm{ch},m}$ 多了上横线，表示事先给定的充电功率上限。

| 写法 | 怎样读 |
|---|---|
| $\overline x$、$\underline x$ | 参数或变量的上限、下限；不是平均值和下划线装饰 |
| $x_t$、$x_{t+1}$ | 当前时段与下一时段，后者不是指数 |
| $\mathcal M$、$\mathcal U$ | 移动储能、无人机的设备类别标签 |
| $\mathrm{RES}$ | 可再生能源类别，本文主要是光伏与风电 |
| $F$、$W$ | 光纤和无线通信类别 |
| $g$、$l$、$f$ | 依语境表示供给、负荷或缺供、流；特别是通信里的 $l$ 存在语义冲突 |
| $\forall$、$\in$、$\setminus$ | 对所有、属于、从集合中排除 |
| $\sum$、$\min$、$\max$ | 求和、取较小值、取较大值或做最大化优化，依上下文区分 |
| $\lvert\mathcal S\rvert$ | 集合 $\mathcal S$ 的元素个数 |
| $\mathrm{s.t.}$ | 满足后列约束，来自 subject to |

## 1. 集合、索引与时间

| 符号 | 含义与来源 | 使用时需要注意 |
|---|---|---|
| $\mathcal N$ | 配电网节点集合 | 原符号表写“节点数量”，但正文用 $i\in\mathcal N$，实际按集合使用 |
| $N=\lvert\mathcal N\rvert$ | 本笔记可采用的规范化节点数记法 | 原式（15）实际仍印作 $\mathcal N$，把集合符号当数量；不是原文单独定义了 $N$ |
| $\mathcal G,\mathcal G_{cn}$ | 配电图、通信图 | 第 III 节总起引入，由对应节点集合和边集合构成 |
| $\mathcal N_{cn}$ | 通信节点集合 | 通信节点编号与电气母线编号需要对应关系 |
| $\epsilon$、$\epsilon_{cn}$ | 电力支路集合、通信边集合 | 原符号表也称“数量”，但约束中是集合；不能直接拿集合参与减法 |
| $\epsilon_d$、$\epsilon_u$ | 相对当前电气节点的流出、流入支路集合 | 节点依赖被原文省略；固定方向用于记账，不妨碍实际潮流反向 |
| $\epsilon_{cd}$、$\epsilon_{cu}$ | 相对当前通信节点的流出、流入边集合 | 用于商品流守恒 |
| $\mathcal N_s$ | 变电站节点集合 | 式（4）（5）用它排除主网节点 |
| $\mathcal N_t^{\mathrm{source}}$ | 时段 $t$ 中配电网的供电源节点集合 | 含形成供电岛的源节点，集合如何随接入状态变化需要实现补充 |
| $\mathcal N_{cn}^{\mathrm{source}}$ | 通信源节点集合 | 通常对应中央控制端；论文公式以集合表示 |
| $\mathcal N_B$ | 符号表中的 MESS 候选节点 | 正文主要改写为 $\mathcal N_C$，原文没有清晰声明两者关系 |
| $\mathcal N_C$、$\mathcal N_c$ | 正文的 MESS 候选接入/充电节点集合 | 大小写与字体有混用；不能与 $\mathcal N_{cn}$ 混淆 |
| $\mathcal N_H$ | UAV 候选驻留/接入节点集合 | 是否服务点与充电点完全相同，原文描述不够明确 |
| $\epsilon_{dg}$、$\epsilon_{st}$ | 式（21）中排除的两类支路集合 | 原文未充分给出精确定义，不能仅凭下标断定类别；详见第 04 篇 |
| $B$、$A_v$ | MESS 数量、UAV 数量 | 公式写 $m\in B$、$z\in A_v$ 时又把它们当设备索引集合；实现应区分数量与集合 |
| $i,j$ | 一般节点或支路两端节点 | 多数情况下在配电网中；UAV 路由也沿用它们 |
| $n$ | 通信节点索引 | 不能无条件等同于电力节点 $i$ |
| $m,z$ | MESS 编号、UAV 编号 | 原符号表“MESS and UAV buses”不够精确，主体公式实际索引设备 |
| $r$、$\mathcal B_n$ | 与第 $n$ 个通信节点关联的发电节点/资源索引及其集合 | 出现在式（34）；不泛指任意负荷节点，$r$ 在此不是电阻 |
| $c$、$w_1,w_2$ | 中央通信节点、路径上的中间节点 | 出现在式（35）的路径展开 |
| $v$ | 式（35）第三项出现的索引 | 原文没有清楚定义，不能自行断定等于 $n$ |
| $t$、$s$ | 当前时段、路由窗口中的另一时段 | $s$ 在式（25）（39）中作为求和索引 |
| $T$ | 恢复期末时刻/总时段数 | 算例为 $24\,\mathrm h$，以 $1\,\mathrm h$ 为间隔 |
| $\Delta t$ | 每个调度时段的时长 | 出现在 SOC 更新中；与功率的时间单位要匹配 |

**教学规范化。** 真正编程时可以另设设备索引集合 $\mathcal B=\{1,\ldots,B\}$、$\mathcal A=\{1,\ldots,A_v\}$ 与时间集合 $\mathcal T=\{1,\ldots,T\}$。这能消除“数字怎么可以写属于”的混乱，但这些是本笔记为说明引入的规范记法，不是原文新增的三个定义。

## 2. 电力网络参数与变量

| 符号 | 含义 | 属性与量纲 |
|---|---|---|
| $r_{ij},x_{ij}$ | 线路电阻、电抗 | 给定参数；用实际值时是 $\Omega$，标幺模型中为标幺阻抗 |
| $P_{ij,t},Q_{ij,t}$ | 支路的有功、无功潮流 | 连续变量；有功用 $\mathrm{kW}$ 或 $\mathrm{MW}$，无功用 $\mathrm{kvar}$ 或 $\mathrm{Mvar}$，也可统一标幺 |
| $\overline P_{ij},\overline Q_{ij}$ | 支路有功、无功幅值上限 | 给定参数；与对应潮流同量纲 |
| $pg_{i,t},qg_{i,t}$ | 节点资源侧等效有功、无功注入 | 连续变量；原文称发电量，但允许负值，尚未减去用户负荷；总节点净注入才是 $pg_{i,t}-pl_{i,t}$ 等 |
| $\overline{pg}_i,\overline{qg}_i$ | 节点供给的幅值上限 | 式（8）（9）对正、负方向都使用这两个上限 |
| $pl_{i,t},ql_{i,t}$ | 实际恢复的有功、无功负荷 | 连续变量；不是失供负荷，越大表示恢复越多 |
| $\overline{pl}_i,\overline{ql}_i$ | 节点原有或最大需恢复负荷 | 给定参数；比例 $\overline{ql}_i/\overline{pl}_i$ 用于保持负荷功率因数 |
| $P^{\mathrm{RES}}_{i,t},Q^{\mathrm{RES}}_{i,t}$ | 可再生电源的有功、无功供给 | 正文用于节点供给分解；预测出力、可调范围及限发方式需在实现中明确 |
| $V_{i,t}$ | 节点电压幅值 | 可用 $\mathrm{V}$、$\mathrm{kV}$ 或标幺值；算例图用标幺值 |
| $U_{i,t}$ | 电压幅值平方，$U_{i,t}=V_{i,t}^{2}$ | 连续变量；若 $V$ 是标幺值，则为其平方 |
| $\overline U_i,\underline U_i$ | 平方电压上、下限 | 不是电压幅值本身的上下限 |
| $\beta_{ij,t}$ | 支路是否闭合并接入供电拓扑 | 二元变量；$1$ 表示闭合，$0$ 表示断开 |
| $st_{ij,t}$ | 线路是否完好/已修复可用 | 原文定义为修复状态；算例给定维修时间，不是维修队调度结果 |
| $st^0_{ij,t}$ | 原符号表称初始支路连接状态 | 虽有 $t$ 下标仍称初始；在式（21）约束特定支路，不等同于实时开关决策 |
| $\omega_i$ | 节点负荷重要性权重 | 式（1）中引入；通常按无量纲相对权重理解，但本文没有公开完整权重表 |
| $M$ | 足够大的常数，即 Big-M | 不是 MESS 类别 $\mathcal M$；电压约束与流约束中所需量纲、数值规模不同 |

**教学补充：有功和无功。** 有功对应被负荷实际消耗的平均功率；无功参与交流系统的电压与电流关系。二者都影响线路和电压约束，因此恢复负荷不仅要有足够的有功电源。本文分别限制两者，但这并不自动等价于完整的视在功率圆约束。

**功率方向。** $P_{ij,t}>0$ 表示沿选定的 $i\to j$ 方向输送，$P_{ij,t}<0$ 表示实际反向。$P^{\mathcal M}_{i,t}>0$ 在模型式（32）中表示储能向电网净注入；而图 6(a) 绘图采用“充电为正、放电为负”，二者是相反的观察方向。

## 3. 拓扑与虚拟潮流

| 符号 | 含义 | 来源与边界 |
|---|---|---|
| $\mathcal N_t^{MG}$ | 时段 $t$ 的微电网/供电岛数量 | 虽然是花体符号，式（15）（16）中实际当数量使用 |
| $\mathcal N_{t,\min}^{MG},\mathcal N_{t,\max}^{MG}$ | 允许的供电岛数量上下限 | 原文未给出全部算例取值 |
| $cf_{ij,t}$ | 电力拓扑中的虚拟流 | 连续变量；是连通性证据，不是有功功率 |
| $cg_{i,t}$ | 源节点生成的虚拟流 | 人为构造的流量，不能当成真实发电 |
| $cd_{i,t}$ | 非源节点消耗的虚拟需求 | 必须有合理的正需求或激活关系，才有强制连通作用 |

虚拟流的“单位”可以理解为抽象连通凭证。一条已闭合支路既可以承载真实功率 $P_{ij,t}$，也可以在数学模型中承载虚拟流 $cf_{ij,t}$；这两个变量解决不同问题，不把数值相加。

## 4. MESS 与 UAV 的共同符号

下表将 $d$ 临时作为设备编号、$\mathcal K\in\{\mathcal M,\mathcal U\}$ 作为设备类别，**只用于本表压缩解释，原文没有引入这个统一符号**。具体使用时分别替换为 $m,\mathcal M$ 或 $z,\mathcal U$。

| 原文对应符号 | 含义 | 属性、单位与来源 |
|---|---|---|
| $\alpha^{\mathcal M}_{m,i,t},\alpha^{\mathcal U}_{z,i,t}$ | 设备是否在节点连接/驻留 | 二元；不直接给出三维坐标 |
| $\lambda^{\mathcal M}_{m,t},\lambda^{\mathcal U}_{z,t}$ | 设备是否处于旅行状态 | 二元；原式实际上是“未连接任一候选点” |
| $\zeta^{\mathcal M}_i,\zeta^{\mathcal U}_i$ | 节点最多可容纳多少设备 | 非负整数参数 |
| $tr^{\mathcal M}_{ij},tr^{\mathcal U}_{ij}$ | 候选点之间旅行时间 | 离散约束需换算为时段数；算例以小时给出 |
| $SOC^{\mathcal M}_{m,t},SOC^{\mathcal U}_{z,t}$ | 荷电状态 | 电量占额定能量的比例，无量纲；$0.8$ 表示 $80\%$ |
| $\underline{SOC}^{\mathcal K}_d,\overline{SOC}^{\mathcal K}_d$ | 允许 SOC 范围 | 参数；MESS 原式（27）错用了 $z$ 下标 |
| $P^{\mathcal K}_{\mathrm{ch},d,t},P^{\mathcal K}_{\mathrm{dch},d,t}$ | 充电、放电功率大小 | 非负连续量，不通过正负号互相替代 |
| $\overline P^{\mathcal K}_{\mathrm{ch},d},\overline P^{\mathcal K}_{\mathrm{dch},d}$ | 充放电功率上限 | 参数；原文部分上限误用设备编号或多出时间下标 |
| $\chi^{\mathcal K}_{d,t},\xi^{\mathcal K}_{d,t}$ | 是否开启充电、放电模式 | 二元开关；允许等于 $1$ 且功率为 $0$，不代表一定满功率运行 |
| $\eta^{\mathcal M}_m,\eta^{\mathcal U}_z$ | 充放电效率 | 无量纲；原文用同一效率描述两个方向，符号表 UAV 下标又写成 $m$ |
| $E^{\mathcal M}_{\mathrm{rated},m},E^{\mathcal U}_{\mathrm{rated},z}$ | 额定能量 | $\mathrm{kWh}$ 或 $\mathrm{MWh}$，不是额定功率 |
| $P^{\mathcal M}_{i,t},Q^{\mathcal M}_{i,t}$ | 节点处所有 MESS 的净有功、无功贡献 | 由连接状态和设备功率汇总 |
| $Q^{\mathcal M}_{m,t},\overline Q^{\mathcal M}_m$ | 单台 MESS 的无功功率及上限 | 式（33）、（58）（59）使用；无功能力的完整约束未充分交代 |
| $P^{\mathcal U}_{i,t}$ | 节点处 UAV 的净有功贡献 | 式（47）按“放电减充电”写，不能自动当作已解释清楚的飞行耗能模型 |

SOC 更新来自能量守恒。**教学补充**：对额定能量为 $E_{\mathrm{rated}}$ 的电池，当前储能是 $E_t=SOC_t E_{\mathrm{rated}}$；在一时段内加上充电得到的能量、减去放电支出的能量，再除以 $E_{\mathrm{rated}}$ 就得到下一时刻的 SOC。充电乘效率，放电除效率，是因为损耗发生方向不同，详见第 05、07 篇。

## 6. 单位、初始条件和原文未明确的部分

若功率用 $\mathrm{kW}$，时间用 $\mathrm h$，则功率乘时间得到 $\mathrm{kWh}$。所以 SOC 更新中 $P\Delta t/E_{\mathrm{rated}}$ 是无量纲。若功率换为 $\mathrm{MW}$，额定电量也必须换成 $\mathrm{MWh}$，不能让二者差一千倍。

功率目标 $\sum_t\sum_i\omega_i pl_{i,t}$ 没有显式乘 $\Delta t$。在等长时段下，它与乘上固定时长的加权恢复能量目标有相同最优方案，但数值及单位不能不加说明地混用。表 VII 的能量与表 VIII 的加权目标也不是同一指标。

原文没有完整公开每类变量的上下界、全部初始位置等式、SOC 参数表、源节点激活方式和终端条件。正文说“初始满电”，图中多个 SOC 曲线却从 $0.8$ 开始；可以怀疑作者把允许的上限当作“满电”，但没有依据把这个猜测写成确定配置。

实际复现前，应把“数量/集合混用”“候选点/充电点是否相同”“电力节点/通信节点对应”“时段开始/结束的状态”全部固定下来。它们不是文字润色问题，而会改变模型的可行域。
